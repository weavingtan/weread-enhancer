# 设计文档：双栏模式左侧文件树（覆盖式）

日期：2026-11-09
状态：已确认（用户批准「实现吧」）
版本：v0.37.9

## 一、问题

用户习惯双栏翻页阅读。双栏正文是 Canvas 位图，微信读书按自己的版心渲染：

- 改容器宽度不一定触发重排，可能裁切/挤压正文（历史尝试 f343a6f 收窄 → 530ff6a 改为「只量留白」）；
- 留白不足时侧栏整块隐藏，双栏下几乎永远看不到左侧文件树，画面上就只剩「白底卡片 + 两栏文字」，
  远看仍然像阅读器。

用户明确诉求：**只要看起来不像微信读书就行**，不接受紧急遮挡/老板键那类额外机制。

## 二、方案

不改正文一个像素，把侧栏「盖」在书页左侧的页边空白上。

1. **量真实空白**：读最左侧双栏 Canvas 的像素，从上到下稀疏采样（每 10 CSS px 一行，避开顶部 5% /
   底部 8%），找第一列与背景色不同的 x，换算成页面坐标即为正文视觉左边界。
   - 背景色取 Canvas 左上角像素；若透明（alpha < 12）则以 alpha > 24 判定墨迹。
   - 结果按 `canvas 位置/尺寸` 缓存，窗口尺寸或字体变化才重算。
2. **自适应宽度**：`可用宽 = 正文左边界 - 10px`，落在 `[120, 248]` 区间时显示侧栏并使用该宽度；
   小于 120px 直接隐藏（宁可没有，也不压字）。
3. **纯覆盖层**：侧栏仍是 `position: fixed`，不透明背景 + 右侧 1px 边框，z-index 高于 Canvas。
   因为盖的是书页页边距，正文完全不受影响，也不需要 Canvas 重排。
4. **窄栏适配**：双栏侧栏可能只有 120px 宽，收紧内边距、隐藏 `kbd` 提示、文件名单行截断。

失败兜底：读不到 Canvas 像素时退回 DOM 边界测量；仍然量不到就不显示侧栏，绝不猜。

## 三、不变量

- 不修改 Canvas 尺寸、不缩放正文、不注入 resize 驱动重排。
- 不改动微信读书原生 DOM 结构（只加 `<html>` 上的 class 控制显示）。
- 侧栏宽度只由留白决定，任何情况下不与文字重叠。

## 四、验收

1. 双栏模式下面包屑/顶栏之下能看到左侧文件树，正文位置、字号、分页与未开插件时一致。
2. 窗口拉宽 → 侧栏变宽至 248px；窗口变窄 → 侧栏变窄或隐藏，不出现压字。
3. 滚动模式侧栏行为不变（收窄正文 + 居中，`.app_content` 规则）。
4. 退出伪装（G）后侧栏消失、正文恢复原样。
